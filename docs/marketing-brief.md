## 3. 누구에게 파는가

**광고 타깃은 어른이다. 학생이 아니다.**

이유가 둘이다. 메타는 미성년자 타깃팅을 나이·지역·성별로만 허용한다. 그리고 실제로 앱을
깔게 만드는 사람은 학부모와 과외쌤이다.

### 1순위 — 과외 선생님 (개인 과외·소규모 교습)

- 20~40대, 학생 1~10명을 개인적으로 가르침
- **아픈 지점**: 지난주에 낸 숙제를 했는지 물어봐야만 알 수 있다. "했어요"를 믿을 수밖에 없다.
  학생마다 카톡·노션·수기 노트로 흩어져 관리한다
- **주는 것**: 한 계정에서 학생별 숙제·진도. 캘린더에서 바로 숙제 제안, 학생이 수락/거절.
  숙제 변경·완료를 푸시로 즉시

### 2순위 — 중고등학생 학부모

- 30~55대, 자녀가 중1~고3
- **아픈 지점**: 아이가 공부했다고 하는데 확인할 방법이 없다. 스마트폰을 붙잡고 있는데
  공부하는 건지 아닌지 모른다
- **주는 것**: 과외쌤과 같은 관리자 화면. 실제 공부한 시간이 기록됨.
  공부 중엔 미리 고른 앱만 열리는 "딴짓 멈춰"

### 최종 사용자 (타깃 아님, 문구에서 언급은 함)

중1~고3 학생. 앱을 실제로 쓰는 사람이지만 광고를 보는 사람은 아니다.

## 4. 핵심 차별점 — 이 순서로 밀 것

**① 기록이 남는다 (가장 강한 차별점)**

못 한 분량은 남은 날짜에 자동으로 다시 나눠 담는다. **그런데 못 한 날의 ×는 캘린더에 그대로
남는다.** 따라잡을 길은 열어주되 기록을 지워주지는 않는다.
→ "말이 아니라 기록으로 확인"

**② 딴짓 멈춰 (안드로이드 전용)**

공부 중엔 미리 고른 앱만 열린다. 차단 목록이 아니라 **허용 목록** 방식이라 새 앱을 깔아도
빠져나갈 수 없다. 쉬는 시간을 쓰면 잠시 풀리고 끝나면 알아서 돌아온다.

**③ 실제 공부 시간이 기록됨**

타이머 시작/일시정지로 붙잡고 있던 시간이 아니라 실제로 공부한 시간이 남는다.

## 5. 전체 기능 (사실 목록)

- 오늘의 할 일 — 과외쌤이 낸 숙제와 학생이 스스로 세운 계획을 한 화면에서
- 실시간 학습 타이머 (시작 / 일시정지 / 완료)
- 숙제 제안 — 과외쌤이 캘린더에서 제안, 학생이 수락 또는 거절
- 캘린더 — 날짜별 완료율이 색 링으로, 시험일·수업일 표시
- 밀린 숙제 자동 재분배
- 과외쌤 대시보드 — 학생별 숙제·진도를 한 계정에서
- 학습설계 — 시험 범위를 날짜에 나눠 배정, 과목별 목표(등급·점수·등수)
- 푸시 알림 — 숙제 등록/변경, 학습 완료, 숙제 미시작 알림 (안드로이드 앱)
- 학교 시간표 — 과외쌤도 함께 봄
- 모의고사 타이머 — 과목별 실제 시험시간 카운트다운
- 딴짓 멈춰 — 허용 앱만 열림 (안드로이드 전용)
- 다크 모드

## 6. 절대 쓰면 안 되는 표현

**성적 보장·향상 주장 금지.** 근거 데이터가 없고, 교육 성과 주장은 메타 광고 정책과
한국 표시광고법 양쪽에서 문제가 된다.

- ✗ "성적이 오릅니다" "1등급 만들기" "○○점 상승"
- ✗ "국내 1위" "가장 많이 쓰는" — 파일럿 단계라 사실이 아니다
- ✗ 사용자 수·후기 수치 — 아직 없다
- ✗ "완전 차단" "절대 못 뚫음" — 딴짓 멈춰는 접근성 서비스 기반이라 사용자가 끌 수 있다
- ✗ 학생 실명·성적·사진 — 실제 데이터는 어떤 형태로도 광고에 쓰지 않는다
- ✗ 불안 조장 ("이대로 두면 늦습니다" 류) — 메타가 정책 위반으로 잡는 패턴이고,
  학부모 대상으로는 반감이 크다

**꼭 밝혀야 할 것**

- "딴짓 멈춰"를 말할 때는 **(안드로이드 전용)** 을 함께
- 무료라고 할 때는 "지금은 전부 무료 (파일럿 단계)"

## 7. 광고 문구 소재

### 과외쌤 대상

헤드라인
- 숙제 냈는데, 했는지는 물어봐야 아셨죠
- 학생 5명 숙제를 카톡으로 관리하고 계신가요
- 과외 숙제, 했는지 안 했는지 그대로 남습니다

본문
- 캘린더에서 숙제를 내면 학생 앱에 바로 뜹니다. 학생이 수락하고, 타이머로 공부하고,
  완료하면 알림이 옵니다. 학생별로 한 계정에서 봅니다. 지금은 전부 무료입니다.
- 밀린 분량은 남은 날짜에 자동으로 다시 나눠 담습니다. 그런데 못 한 날은 캘린더에 그대로
  남습니다 — 따라잡을 길은 열어주되, 기록을 지워주지는 않습니다.

### 학부모 대상

헤드라인
- "공부했어" 를 확인할 방법
- 폰 붙잡고 있는데 공부하는 건지 모르시겠다면
- 오늘 뭘 했는지, 얼마나 했는지 남습니다

본문
- 공부 중엔 미리 고른 앱만 열립니다. 쉬는 시간을 쓰면 잠시 풀리고, 끝나면 알아서 돌아옵니다.
  실제 공부한 시간이 기록으로 남습니다. (앱 잠금은 안드로이드 전용)
- 과외쌤과 같은 화면을 봅니다. 숙제를 했는지, 얼마나 했는지 캘린더에 그대로 쌓입니다.

## 8. 랜딩 · 전환 경로 (여기가 병목이다)

```
광고 클릭 → studybuks.store → ┬ [웹앱 열기]  → 설치 없이 즉시 사용 ✅
                              └ [APK 다운로드] → "출처를 알 수 없는 앱" 허용 필요 ⚠️
```

**중요: 앱 설치가 아니라 웹앱을 1차 전환으로 잡을 것.**

- 플레이 스토어에 없다 → 메타의 "앱 설치" 캠페인 목표를 쓸 수 없다.
  **트래픽 / 랜딩 전환** 목표로 돌려야 한다
- APK 설치는 경고 화면을 넘겨야 해서 이탈이 크다
- 반면 웹앱은 설치 없이 즉시 쓸 수 있고, 숙제 관리·타이머·대시보드가 전부 웹에서 된다
  (딴짓 멈춰만 앱 필요)
- 아이폰 사용자도 웹앱은 정상이다 — 사파리 → 공유 → "홈 화면에 추가"

**타깃 설정 권장**

- 지역: 한국
- 나이: 25~55 (학부모·과외쌤). **18세 미만 제외**
- OS: 딴짓 멈춰를 앞세운 소재는 **안드로이드만**. 나머지는 전 기기
- 관심사: 과외, 학습지, 입시, 자녀 교육

## 10. 광고를 돌리기 전에 정할 것

1. **예산과 목표를 먼저 정한다.** 파일럿 단계라 지금 필요한 건 규모가 아니라
   "과외쌤 5~10명이 실제로 써보고 피드백을 주는 것"일 수 있다.
   그렇다면 광고보다 직접 접촉이 싸고 빠르다
2. **웹앱 전환을 측정할 수 있는지 확인한다.** 랜딩에 Amplitude가 붙어 있고
   `Clicked Download Apk` / `Clicked Start App` 이벤트가 이미 있다.
   메타 픽셀은 아직 없다 — 전환 최적화를 하려면 픽셀부터 붙여야 한다
3. **플레이 스토어 등록을 먼저 할지 판단한다.** 앱 설치를 진짜 목표로 삼을 거라면
   스토어 등록이 광고보다 먼저다
