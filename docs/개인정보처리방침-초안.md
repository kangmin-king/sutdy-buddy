## 1. 총칙

{{운영자}}(이하 "운영자")는 학습 관리 서비스 **스터디 벅스**(웹 `app.studybuks.store`,
안드로이드 앱)를 제공하면서 이용자의 개인정보를 아래와 같이 처리합니다.

스터디 벅스는 학생과 관리자(과외 선생님 · 학부모)가 **같은 숙제를 서로 다른 화면으로 보는**
구조입니다. 그래서 학생이 입력한 학습 기록의 일부가 연결된 관리자에게 보입니다. 이 방침은 그
범위를 분명히 하는 데 목적이 있습니다.

## 2. 수집하는 개인정보 항목과 목적

### 2.1 계정

| 항목 | 목적 | 필수 |

| 비밀번호 | 인증 (Supabase Auth가 해시로만 보관하며, 운영자는 원문을 볼 수 없습니다) | 필수 |
| 역할 구분 (학생 / 과외쌤·학부모) | 역할에 맞는 화면 제공 | 필수 |

| 주요 과목, 학습 목표, 시험 예정일, 사용 교재 | 숙제·계획 구성 |

### 2.3 학습 데이터

| 항목 | 목적 |
| --- | --- |

| 스스로 세운 계획(플래너) 항목 | 서비스 핵심 기능 |
| 학습 세션 기록 (시작 시각, 종료 시각, 공부한 시간) | 실제 학습 시간 기록 및 관리자 확인 |

| 학생 ↔ 관리자 연결 관계 | 누가 누구의 기록을 볼 수 있는지 결정 |

### 2.4 알림

| 항목 | 목적 |
| --- | --- |
| FCM 기기 토큰 (Firebase Cloud Messaging) | 푸시 알림 발송 |
| 숙제 알림 설정값, 알림 발송 로그 | 알림 시각 설정 및 중복 발송 방지 |

### 2.5 "딴짓 멈춰" 관련 (안드로이드 앱 전용)

이 기능은 **안드로이드 접근성 서비스**와 **다른 앱 위에 표시**(SYSTEM_ALERT_WINDOW) 권한을
사용합니다. 이용자가 직접 켜야 동작하며, 언제든 끌 수 있습니다.

| 처리 내용 | 어디까지 나가는지 |
| --- | --- |
| 지금 화면에 떠 있는 앱의 패키지명 | **기기 안에서만** 판단에 쓰이고 서버로 전송되지 않습니다 |
| 기기에 설치된 앱 목록 | 허용할 앱을 고르는 화면에만 쓰이며 서버로 전송되지 않습니다. 안드로이드의 `<queries>` 선언으로 필요한 범위만 조회하고, 전체 앱 목록 조회 권한(`QUERY_ALL_PACKAGES`)은 사용하지 않습니다 |
| 공부 중 허용앱을 사용한 시간 구간 (시작·종료 시각) | 서버에 저장되고 연결된 관리자가 볼 수 있습니다. **어떤 앱을 썼는지는 저장하지 않습니다** — 관리자에게 필요한 정보는 "얼마나 오래"이고 "무엇을"이 아니기 때문입니다 |

### 2.6 서비스 이용 분석

운영자는 Amplitude를 사용해 서비스 개선을 위한 이용 행태를 분석합니다.

| 항목 | 내용 |
| --- | --- |
| 이벤트 로그 | 화면 조회, 세션 시작·종료, 유입 경로(UTM·referrer), 주요 기능 사용 이벤트 |
| 이용자 식별자 | 로그인 후에는 계정의 내부 식별자(UUID)가 함께 전송됩니다. 이름·이메일은 전송하지 않습니다 |
| 이용자 속성 | 학년, 역할, 연결된 사람 수, 누적 학습 세션 수 등 |
| **세션 리플레이** | **현재 전체 세션(100%)에 대해 화면 조작 기록이 수집됩니다.** 이용자가 앱에서 어떤 순서로 무엇을 눌렀는지 재생할 수 있는 형태입니다 |

> ⚠️ **세션 리플레이는 별도 동의를 받는 것이 안전합니다.** 지금은 코드상
> `sessionReplay: { sampleRate: 1 }` 로 항상 켜져 있습니다. 게시 전에 (1) 선택 동의 항목으로
> 분리하거나 (2) 표본율을 낮추거나 (3) 최소한 이 방침에 위와 같이 명시하고 동의를 받는 절차를
> 두시길 권합니다.

### 2.7 자동으로 생성되는 정보

접속 시각, IP 주소, 브라우저·기기 정보는 서비스 제공에 쓰이는 인프라(Vercel, Supabase)에서
접속 기록 형태로 생성·보관됩니다.

## 3. 수집하지 않는 것

오해를 막기 위해 명시합니다. 스터디 벅스는 다음을 수집하지 않습니다.

- 이름, 생년월일, 전화번호, 주소, 학교명
- 사진, 연락처, 위치 정보, 마이크·카메라 접근
- 결제 정보 (결제 기능 자체가 구현되어 있지 않습니다)
- 어떤 앱을 사용했는지에 대한 기록 (사용 **시간**만 저장합니다)

## 4. 만 14세 미만 아동

스터디 벅스는 중학교 1학년부터 이용할 수 있어, **만 14세 미만 아동이 가입할 수 있습니다.**

「개인정보 보호법」 제22조의2에 따라 만 14세 미만 아동의 개인정보를 처리하려면 법정대리인의
동의를 받아야 하고, 그 동의를 확인할 수 있어야 합니다.

> ⚠️ **현재 서비스에는 이 절차가 구현되어 있지 않습니다.** 방침 문서만으로는 해결되지 않는
> 사항입니다. 게시 전에 아래 중 하나를 정해야 합니다.
>
> 1. 가입 시 생년(또는 만 14세 이상 여부)을 확인하고, 만 14세 미만이면 법정대리인 동의 절차를
>    거치게 한다 — 스터디 벅스는 학부모가 관리자 계정으로 함께 쓰는 구조이므로, **연결된
>    관리자(학부모)의 동의를 동의 절차로 설계하기가 비교적 자연스럽습니다.**
> 2. 이용 대상을 만 14세 이상으로 제한하고 가입 시 확인한다.
>
> 어느 쪽이든 코드 변경이 필요합니다.

## 5. 개인정보의 제3자 제공

운영자는 이용자의 개인정보를 제3자에게 판매하거나 제공하지 않습니다.

다만 서비스 구조상 **연결된 관리자(과외 선생님 · 학부모)는 학생의 학습 데이터를 볼 수
있습니다.** 이는 제3자 제공이 아니라 서비스의 기능이며, 학생이 관리자와 연결을 수락한 범위에
한정됩니다. 볼 수 있는 범위는 다음과 같습니다.

- 숙제 배정 및 완료 여부
- 학습 세션 기록(공부한 시간)
- 플래너 항목, 캘린더 완료율
- 공부 중 허용앱 사용 시간 구간 (어떤 앱인지는 제외)
- 학교 시간표, 모의고사 기록

연결은 학생이 수락해야 성립하며, 데이터베이스 수준의 접근 제어(Row Level Security)로
연결되지 않은 사람은 조회할 수 없도록 막혀 있습니다.

## 6. 개인정보 처리의 위탁 및 국외 이전

서비스 운영을 위해 다음 사업자의 인프라를 이용하며, 이들의 서버는 국외에 있습니다.

| 수탁자 | 위탁 업무 | 이전되는 항목 | 이전 국가 |
| --- | --- | --- | --- |
| Supabase Inc. | 인증, 데이터베이스, 서버리스 함수 | 2장의 계정·프로필·학습·알림 데이터 | 미국 등 |
| Vercel Inc. | 웹 호스팅 | 접속 기록 | 미국 등 |
| Google LLC (Firebase Cloud Messaging) | 푸시 알림 발송 | 기기 토큰, 알림 내용 | 미국 등 |
| Amplitude, Inc. | 이용 행태 분석, 세션 리플레이 | 2.6의 분석 데이터 | 미국 등 |

각 사업자의 개인정보 보호 수준 및 정책은 해당 사업자가 공개한 문서를 따릅니다.

## 7. 보유 및 이용 기간, 파기

- 계정 정보 및 학습 데이터는 **회원 탈퇴 시까지** 보유합니다.
- 탈퇴하면 계정과 그에 연결된 학습 데이터는 함께 삭제됩니다. 데이터베이스의 모든 학습 관련
  테이블이 계정에 `on delete cascade` 로 연결되어 있어, 계정을 지우면 그 사람의 숙제·학습
  세션·플래너·시험 기록·기기 토큰이 함께 지워집니다.
- 법령에서 보존을 요구하는 기록이 있는 경우 해당 기간 동안 분리 보관 후 파기합니다.
- 분석 도구(Amplitude)에 축적된 이벤트 데이터 및 세션 리플레이는 해당 서비스의 보존 정책을
  따릅니다. 계정을 지워도 자동으로 삭제되지 않으므로, 요청 시 별도로 삭제 처리합니다.

> ⚠️ **현재 앱에는 이용자가 스스로 탈퇴할 수 있는 기능이 없습니다.** (2026-09-03 확인:
> `auth.admin.deleteUser` 호출은 `supabase/functions/delete-admin-user` 하나뿐이고, 그것은
> 관리자 패널에서 **어드민 계정**을 지우는 용도입니다.)
>
> 이건 두 가지 이유로 그냥 둘 수 없습니다.
>
> 1. 「개인정보 보호법」상 정보주체의 삭제 요구권을 보장해야 합니다.
> 2. **구글 플레이는 계정 생성이 가능한 앱에 계정·데이터 삭제 경로를 요구합니다.** 앱 안에서
>    삭제할 수 있거나, 앱 밖에서 삭제를 요청할 수 있는 웹 링크를 스토어 등록 정보에 제출해야
>    합니다. 없으면 심사에서 막힙니다.
>
> 최소 조치는 문의 창구로 탈퇴 요청을 받아 수동 처리하는 것이고(이 방침에 그 창구를 명시),
> 제대로 된 조치는 설정 화면에 탈퇴 버튼을 넣는 것입니다.

## 8. 이용자의 권리와 행사 방법

이용자(만 14세 미만인 경우 법정대리인)는 언제든 다음을 요구할 수 있습니다.

- 개인정보 열람
- 오류의 정정
- 삭제
- 처리 정지

요구는 `{{보호책임자_연락처}}` 로 하실 수 있으며, 운영자는 지체 없이 조치합니다.
서비스 안에서 직접 할 수 있는 것도 있습니다 — 프로필 수정, 관리자 연결 해제, 알림 설정 변경,
"딴짓 멈춰" 권한 해제는 앱에서 바로 가능합니다.

## 9. 안전성 확보 조치

- 모든 통신은 HTTPS로 암호화됩니다.
- 비밀번호는 Supabase Auth가 해시로 보관하며 운영자도 원문을 알 수 없습니다.
- 데이터베이스 테이블마다 Row Level Security를 적용해, 본인과 연결된 관리자만 해당 행을
  조회할 수 있도록 접근 권한을 제한합니다.
- 관리자 권한이 필요한 작업은 별도 관리자 계정 목록으로 제한합니다.
