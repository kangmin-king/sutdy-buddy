# 이 제품이 무엇인가

한국 과외 학습관리 앱. 과외 선생님(또는 학부모) 한 명이 학생 몇 명을 관리합니다.
학생은 오늘 숙제를 보고 타이머로 공부하고 완료를 체크합니다. 매니저는 숙제를 내고, 학생이 했는지
보고, 시험 범위를 날짜별로 쪼개 배정합니다.

- **실사용자는 학생 2명, 매니저 2명.** 파일럿이고 스토어에 없습니다. A/B 테스트는 성립하지 않습니다.
- 모바일 480px 폭 전제. 안드로이드 앱이 주력이고, 아이폰은 웹앱(홈 화면 추가)으로만 씁니다.
- 제품의 전제는 **"숙제를 했는지를 기록으로 증명한다"** 입니다. 이 축을 흐리는 디자인은 값이 없습니다.

# design.md 이후에 바뀐 것 (문서에 아직 없습니다)

1. **초기 로드 실패 화면이 새로 생겼습니다.** 예전에는 프로필 조회가 실패하면 기존 사용자에게
   온보딩이 떴습니다. 지금은 "정보를 불러오지 못했어요 / 인터넷 연결을 확인하고 다시 시도해주세요.
   저장된 학습 기록은 그대로 있어요." + [다시 시도] 버튼입니다. 세로 가운데 정렬, 아이콘 없음.
   **이 화면은 아직 디자인 검토를 안 받았습니다.**
2. **ToggleSwitch를 `<span onClick>`에서 `<button role="switch">`로 바꿨습니다.** 보이는 트랙은
   24px 그대로고 위아래 여백으로 터치 영역만 44px로 넓혔습니다(음수 마진으로 줄 간격은 유지).
3. **타임라인에 "허용앱만 쓴 칸"이 새로 보이게 됐습니다.** 공부 세션이 없는 칸도
   `surface-container-highest` 배경에 `on-surface-variant / 0.7` 대각선 빗금으로 칠합니다
   (라이트 3.55:1 / 다크 4.10:1로 실측). 공부 세션과 겹치는 칸은 과목 색 위에 검은 빗금 그대로입니다.
4. **날짜 다중 선택기(CompactMonthPicker)에 `aria-pressed`와 월·일 라벨을 붙였습니다.** 시각적 변화 없음.
5. 전역 `:focus-visible` 규칙, 라벨-입력 `useId` 연결, 과목 색 점의 인셋 링은 그 전에 넣었습니다.

# 반드시 답해 주셔야 하는 것 — 미결 4건

`design.md` §9에 있는 것들이고 **전부 아직 그대로입니다.** 각각 "어떻게 할지"를 정해 주세요.

**(1) 상단바 알림 벨이 아무 동작도 하지 않습니다.**
`onBell` prop을 받는데 넘기는 화면이 0곳입니다. 누르면 아무 일도 안 납니다.
선택지는 (a) 버튼 제거 (b) 인앱 알림함 신설 (c) 다른 것. 어느 쪽인지와 이유를 주세요.
(b)라면 이 앱에서 알림함이 실제로 담을 내용이 무엇인지까지 말해 주세요 —
푸시는 이미 가고 있고, 알림함이 중복 표면이 되면 안 됩니다.

**(2) 온보딩만 그라데이션을 씁니다.**
`from-primary-container/30 via-secondary-container/20 to-tertiary-container/30`.
앱의 나머지 어디에도 그라데이션이 없어서 혼자 튑니다. 없앨지, 아니면 온보딩에만 있는 것이
정당한지(첫인상 화면이라는 이유가 충분한지) 판단해 주세요.

**(3) 마스코트와 앱 테마가 안 맞습니다.**
마스코트는 흰색·분홍·주황·초록의 **따뜻한 계열 손그림 카와이 토끼**인데, 앱은 파랑·인디고·보라의
**찬 계열**입니다. 게다가 상단바에서 Material Symbols의 얇은 기하선 아이콘과 8px 거리에 붙어 있어
선 두께도 안 맞습니다. PNG에 투명도가 없어서(색타입 2 = RGB) 다크 배경에서는 흰 사각형이 됩니다
(랜딩 CTA는 둥근 흰 상자에 담아 "스티커"로 보이게 임시 처리했습니다).
**마스코트를 리컬러할지, 다시 그릴지, 쓰는 자리를 줄일지** 정해 주세요. 트레이드마크 자산이라
바꾸려면 근거가 필요합니다.

**(4) 학생이 직접 만든 계획을 완료해도 매니저에게 알림이 안 갑니다.**
추가할 때는 갑니다. 어긋나 있습니다. 이건 기능 결정이기도 한데, **디자인 관점에서**
자기계획의 완료가 매니저에게 갈 일인지 판단해 주세요(숙제와 자기계획을 한 목록에 배지로만
구분해 두었는데, 알림 정책이 다르면 그 통합이 거짓말이 됩니다).
