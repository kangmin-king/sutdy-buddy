# 상황

한국 과외 학습관리 앱 「스터디 벅스」. 학생 2명·매니저(과외쌤/학부모) 2명이 쓰는 파일럿입니다.
제품의 전제는 **"숙제를 했는지를 기록으로 증명한다"** 입니다. 감성형 소비 앱이 아니라 도구입니다.

지난번 당신의 최종 디자인 리뷰에서 마스코트를 이렇게 판정했습니다.

> 출시 전: 상단바에서 마스코트를 제거하고 `S` 글자 배지로 교체, 사용처 축소
> 출시 후: 리컬러보다 **재제작**. 투명 배경, 앱 토큰에 맞는 저채도 포인트,
> 사용처는 온보딩·랜딩·빈 상태로 제한, 상단바 반복 노출 금지

**상단바 교체는 하지 않기로 했습니다.** 이유는 아래 "사실 정정"에 있습니다.
v1.2.8은 이미 출시했고, 마스코트는 v1.2.9 과제로 남아 있습니다.

# 사실 정정 — 지난 리뷰의 전제 두 개가 틀렸습니다

**(1) 상단바에서 흰 사각형이 되지 않습니다.**
상단바 마크업이 `rounded-full overflow-hidden` + `object-cover`라 **원으로 잘려서 아바타처럼
읽힙니다.** 흰 사각형이 됐던 것은 랜딩 CTA였고, 그건 둥근 흰 상자로 감싸 이미 해결했습니다.
그래서 "매 화면 반복되는 미완성 신호"라는 근거가 성립하지 않아 상단바는 그대로 뒀습니다.

**(2) 안드로이드 런처 아이콘은 이미 투명합니다.**
`ic_launcher.png`는 192×192 **RGBA**(알파 있음)이고 adaptive icon으로 잘 동작합니다.
투명도가 없는 것은 앱·랜딩이 쓰는 `src/assets`의 PNG 두 개뿐입니다.

# 현재 마스코트 생김새

흰 토끼입니다.

- **굵은 차콜 윤곽선** (약 1.7% 두께 — 820px 기준 14px). 손그림 느낌의 둥근 선.
- 귀 안쪽에 **연분홍**, 뺨에 **분홍 빗금 두 개**(블러시)
- 작고 둥근 검은 눈에 흰 하이라이트 점, 작은 코와 입
- **주황 당근**(초록 잎)을 왼쪽 아래에 들고 있음
- 런처 아이콘 버전은 전신이고 **분홍 배 무늬**가 추가로 있음

# 무엇이 문제인가

**색 계열이 정반대입니다.** 마스코트는 흰색·분홍·주황·초록의 **따뜻한** 계열인데,
앱은 **찬** 계열입니다.

| 토큰 | 라이트 | 다크 |
|---|---|---|
| `primary` | `54 96 149` (남색) | `162 155 242` (연보라) |
| `secondary` | `25 107 80` (초록) | `111 217 174` (민트) |
| `tertiary` | `99 86 142` (보라) | `176 163 224` (연보라) |
| `surface` | `247 249 251` | `27 24 50` (인디고 네이비) |
| `on-surface` | `25 28 30` | `233 232 245` |
| `on-surface-variant` | `66 71 79` | `169 166 196` |
| `outline` | `115 119 128` | `124 120 155` |

**선 두께도 안 맞습니다.** 상단바에서 Material Symbols의 얇은 기하선 아이콘과 8px 거리에
붙어 있는데, 마스코트는 굵은 손그림 선입니다.

**투명도가 없습니다.** 다크 모드에서 원형 마스크 밖으로 나가는 자리(랜딩 CTA 같은)에서는
흰 배경이 그대로 보입니다.

# 결정해 주셔야 할 것

**(1) 방향** — 셋 중 하나를 고르고 이유를 주세요.
   (a) 지금 그림을 유지하고 **투명화만** 한다 (색 불일치는 감수)
   (b) 실루엣과 정체성은 유지하고 **리컬러·선 정리**한다
   (c) **다시 그린다**

   판단 근거로 이걸 고려해 주세요: 실제 표시 크기가 32~56px이라 디테일이 거의 안 보입니다.
   이 크기에서 색 계열 불일치가 정말로 인지되는지, 아니면 문제가 주로 랜딩 히어로(큰 크기)에서만
   생기는지 — 크기별로 판단이 갈린다면 그렇게 말해 주세요.

**(2) 정체성에서 무엇을 지키고 무엇을 버리는가**
   당근? 분홍 블러시? 굵은 손그림 선? 흰 몸통? 각각에 대해 지킬지 버릴지와 이유를 주세요.
   트레이드마크 자산이라 "전부 새로"는 비용이 큽니다.

**(3) 사용처**
   지금은 상단바(36px) · 랜딩 헤더/푸터(32px) · 랜딩 CTA(56px) · 랜딩 히어로(큼) · 런처 아이콘입니다.
   줄일지 유지할지, 줄인다면 어디를 남길지.

# 사양서에 반드시 들어가야 할 것

그림 그리는 사람이 이것만 보고 작업할 수 있어야 합니다.

1. **팔레트** — 각 부위(윤곽선/몸통/귀 안쪽/블러시/눈/당근)의 색을 **앱 토큰 이름 + hex**로.
   라이트·다크 양쪽에서 쓸 하나의 그림이어야 합니다(테마별로 두 벌을 만들 거면 그렇게 명시).
   **`surface`(라이트 `247 249 251`)와 `surface`(다크 `27 24 50`) 양쪽에서** 형태가 읽혀야 하므로,
   윤곽선 색의 대비비를 두 배경 모두에 대해 계산해 주세요(비-텍스트 기준 3:1).
2. **선 두께** — 원본 크기 기준 px와 비율. 32px로 줄였을 때 뭉개지지 않을 하한도.
3. **실루엣** — 32px에서 알아볼 수 있어야 합니다. 원형 마스크(상단바)에 들어갔을 때
   무엇이 잘리는지도 고려해 주세요.
4. **파일 규격** — 포맷(PNG/WebP/SVG), 크기, 알파 필수, 여백(safe area).
   런처 아이콘은 이미 투명하니 건드릴지 여부도 정해 주세요.
5. **이미지 생성 도구용 프롬프트** — 사용자가 그걸로 만들 가능성이 높습니다.
   영어로, 색을 hex로 박아서, 배경 투명을 명시해서 **그대로 복사해 쓸 수 있게** 주세요.
