# 밀린 숙제 자동 재분배 + 진행률 표시 + 오늘의 할 일 버튼 리디자인

## 배경

MVP 완성 후 학생/과외쌤/학부모 입장에서 다듬을 점을 브레인스토밍하다가, 앱의 근본 문제의식("숙제를 몰아서 함, 부모님이 확인 못함")과 직결되는 구조적 공백을 발견했다: 학생 홈화면도 매니저 홈화면도 "오늘 날짜"의 항목만 조회한다(`state.plannerItems[today]`). 학생이 어제 숙제를 안 했으면, 그 항목은 어제 날짜에 `planned` 상태로 남아있을 뿐 오늘 화면 어디에도 보이지 않는다. 학생도 부모님도 밀렸다는 걸 알 방법이 없다.

이 스펙은 이 공백을 메우는 기능(밀린 숙제 자동 재분배, 캘린더 완료 표시, 홈 화면 배너)과, 같은 대화에서 함께 정리된 "오늘의 할 일" 버튼 리디자인을 다룬다.

## 범위

- 페이지 범위로 등록된 숙제(교재 범위, `sb_exam_subject_ranges`)의 자동 재분배
- 자유입력 숙제(모의고사 등)·학생이 스스로 짠 계획의 "어제 못한 것" 노출 + 오늘로 복사
- 학생 캘린더 · 매니저 캘린더 날짜 셀에 완료율 표시(원형 파이 채우기)
- 학생 홈화면: 어제 못한 숙제 배너 + "지금까지 밀린 과제 보기" 버튼
- "오늘의 할 일" 버튼 리디자인(포스트잇 스타일)

**범위 밖(후속 폴리싱으로 미룸):**
- 당근/토끼 마스코트의 최종 아트웍(모양, 색, 배치) — 이번엔 기존 앱의 심플한 색상(primary)으로 파이 채우기 매커니즘만 구현하고, 마스코트 스킨은 나중에 교체한다.
- 매니저 캘린더에 "오늘 타임라인"급 상세 시간대 그리드를 넣는 것 — 이번 스펙은 완료율(%) 표시까지만.

## 설계

### 1. 자동 재분배 (페이지 범위 숙제)

- 대상: `examSubjectRangeId`가 있고 `rangeLabel`이 `N~M페이지` 형식인 항목만. 자유입력(모의고사 등)이나 `source: 'self'` 항목은 대상 아님.
- **놓친 날 판정**: 항목의 `date < 오늘` 이고 `status !== 'completed'` 이면 그 날짜는 "놓친 날"이다. 그 항목 자체는 건드리지 않고 그대로 둔다 — 캘린더에 미완료로 남을 "기록"이자, 홈 배너에 보여줄 원본이다.
- **재분배 계산**: 범위별로 "실제 도달 지점"을 계산한다 — 그 범위에 속한 항목 중 `status === 'completed'`인 것들의 `pageRange` 끝 페이지 중 가장 큰 값(없으면 범위 시작 페이지 - 1). 도달 지점+1부터 범위의 끝 페이지까지 남은 분량을, 그 범위에 속한 아직 완료 안 된 오늘/미래 날짜들(`date >= 오늘`)에 기존 `splitPagesAcrossDates` 함수로 다시 나눠 담는다. 이미 있는 `updateHomeworkAmountForDate`가 수동으로 하던 것과 동일한 계산을 자동으로 돌리는 것이므로, 그 함수의 재분배 부분 로직을 공용 헬퍼로 뽑아 재사용한다.
- **멱등성**: 계산된 새 `pageRange`가 현재 저장된 값과 같으면 DB 쓰기를 생략한다 — 앱을 열 때마다 계산은 하되, 값이 안 바뀌었으면 불필요한 쓰기가 없다.
- **트리거 시점**: 별도 서버(cron)가 없는 구조이므로, "누군가 이 학생의 데이터를 불러올 때" 계산한다 — 학생 본인이 로그인/새로고침할 때(`loadAll`), 그리고 매니저가 그 학생 화면을 열 때(`loadStudentPlannerItems`) 둘 다에서 동일한 헬퍼를 호출한다.

### 2. 자유입력/자기계획 미완료 항목

재분배 대상이 아니므로 그대로 둔다. 대신 "어제 못한 숙제" 배너(4번)에서 항목 옆에 **"오늘 일정에 추가하기"** 버튼을 단다. 누르면 오늘 날짜로 내용이 동일한 새 `PlannerItem`을 생성한다(어제 항목은 미완료 기록으로 그대로 남아 캘린더에 X로 표시됨). 새로 생성되는 이 항목은 `homeworkAssignmentId`/`examSubjectRangeId` 없이 오늘 날짜의 독립 항목으로 만든다(원본과 연결되지 않음 — 원본은 과거 기록용으로 보존).

### 3. 캘린더 완료율 표시

- 학생 캘린더(`StudentCalendar.tsx`)·매니저 캘린더(`ManagerCalendar.tsx`) 둘 다, 과거 날짜의 원형 셀을 `conic-gradient`로 채운다 — 12시 방향부터 시계 방향으로, 그날 항목 중 완료된 비율만큼. 완료율 = 그날 항목 수 중 `status === 'completed'` 비율.
  - 항목이 없는 날: 채우기 없음(현재처럼 빈 원)
  - 오늘/선택된 날짜 표시(파란 원)는 기존 그대로 유지 — 파이 채우기와 겹치지 않음
  - 색은 앱 기존 `primary` 토큰 사용(마스코트 스킨은 후속 작업)
- 날짜를 누르면 그날 항목 목록이 뜨는 기존 동작은 그대로 유지.

### 4. 홈 화면 "어제 못한 숙제" 배너

- `StudentHome.tsx` 최상단(포스트잇 버튼보다도 위)에, 어제 날짜에 `status !== 'completed'`인 항목이 하나라도 있으면 배너를 띄운다.
  - 페이지 범위 숙제: 항목명 표시만 (재분배는 이미 백그라운드에서 처리됨 — 오늘/이후 날짜에 반영됨)
  - 자유입력/자기계획 항목: 항목명 옆에 "오늘 일정에 추가하기" 버튼(2번)
- 배너 옆에 작은 **"지금까지 밀린 과제 보기"** 버튼 — 누르면 캘린더 탭으로 전환(`StudentAppShell`이 관리하는 `activeTab`을 바꾸는 콜백을 `StudentHomeScreen`에 prop으로 전달). 캘린더 탭에서는 3번에서 만든 완료율 표시로 과거 미완료 날짜들을 훑어볼 수 있다.

### 5. "오늘의 할 일" 버튼 리디자인

포스트잇 스타일로 교체한다:
- 노란 메모지(`#fff4a8`), 살짝 회전(-3deg), 그림자로 입체감
- 상단 압정 자리에 당근 이모지(🥕)
- 오른쪽에 아래방향 이중 셰브런(∨∨) — "누르면 아래로 펼쳐진다"는 암시. **애니메이션 없이 정지 상태** (까딱이는 움직임은 산만하다는 피드백으로 제외)
- 클릭 동작(칠판 오버레이 열기)은 기존 그대로 유지

## 데이터 흐름 / 구현 지점

- `src/lib.ts`: 기존 `updateHomeworkAmountForDate`의 재분배 계산 부분을 순수 함수로 추출 (예: `computeRangeRedistribution(range, itemsForRange, fromToday)`) — 테스트 가능하게.
- `src/state/AppStateContext.tsx`:
  - 새 헬퍼 `syncMissedHomework(items, ranges)`: 놓친 날 판정 + 재분배 계산 + 필요한 DB 업데이트만 골라 실행. `loadAll`(학생 본인, `profile.role === 'student'` 분기) 끝에서, 그리고 매니저의 `loadStudentPlannerItems(studentId)` 끝에서 호출.
  - `copyItemToToday(studentId, item)` 액션 추가 (2번의 "오늘 일정에 추가하기").
- `src/screens/student/StudentCalendar.tsx`, `src/screens/manager/ManagerCalendar.tsx`: 날짜 셀에 완료율 conic-gradient 적용.
- `src/screens/student/StudentHome.tsx`: 어제 못한 숙제 배너 + 밀린 과제 보기 버튼(부모 컴포넌트에서 탭 전환 콜백 전달) + 포스트잇 버튼 스타일 교체.
- `src/App.tsx`: `StudentAppShell`에서 `StudentHomeScreen`에 캘린더 탭으로 전환하는 콜백 전달.

## 테스트

- `computeRangeRedistribution` 순수 함수: 놓친 날 뒤 재분배가 올바른 페이지 구간으로 나뉘는지, 연속 여러 날 밀렸을 때도 "완료된 것 중 최대 도달점" 기준으로 한 번에 맞게 계산되는지, 이미 최신 상태면 빈 결과(쓰기 없음)를 반환하는지.
- 기존 `splitPagesAcrossDates`/`updateHomeworkAmountForDate` 테스트는 회귀 없이 통과해야 함.

## 미해결/후속 과제로 남기는 것

- 당근/토끼 마스코트 최종 아트웍
- 매니저 캘린더의 시간대 상세 그리드(3번 범위 밖)
