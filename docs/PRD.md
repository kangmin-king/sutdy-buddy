# 스터디 버디 — PRD (Product Requirements Document)

**최신화 기준일:** 2026-08-07
**브랜치:** `tutor-student-two-track` (PR #1)
**작성 배경:** 투트랙(과외쌤·학부모용 / 학생용) 전환 이후 지금까지 실제로 구현된 기능을 기준으로 정리한 문서. 계획 단계 문서가 아니라 **현재 동작하는 앱의 스냅샷**입니다.

---

## 1. 문제의식 & 방향성

과외를 진행하면서 학생들이 숙제를 매일 하지 않고 몰아서 하는 경우가 많고, 부모님은 이를 확인할 방법이 없다는 문제에서 출발했다.

- **과외쌤/학부모**는 아이의 학습을 확인·관리할 수 있어야 한다 — 숙제를 지정하고, 매일 얼마씩 하도록 정하고, 실제로 했는지 확인.
- **학생**은 최대한 단순한 화면으로, 과외쌤이 짜준 계획 + 스스로 짠 계획을 오늘 할 일로 받아서 시작/완료하면 되는 흐름.

이 문제의식에 따라 기존 단일 앱을 **매니저(과외쌤·학부모)용**과 **학생용**, 두 갈래로 나눴다(투트랙).

---

## 2. 사용자

| 역할 | 정의 | 진입 |
|---|---|---|
| 학생 | 자신의 계정으로 로그인, 초대코드로 과외쌤/학부모와 연결 | 회원가입 시 role 선택 |
| 매니저 (과외쌤 / 학부모) | 학생의 초대코드를 입력해 연결, 여러 학생 담당 가능 | 회원가입 시 role 선택 → 학생 목록에서 코드 입력해 연결 |

한 학생에게 과외쌤과 학부모가 동시에 연결될 수 있다(다대다). 각 매니저는 학생에게 자신만 보는 별칭(라벨)을 붙일 수 있다.

## 4. 기능 명세

### 4.1 매니저 — 학생 선택 & 연동
- 담당 학생 목록에서 학생을 선택하면 상단에 칩으로 고정, 다른 학생으로 즉시 전환 가능.
- 학생별 별칭을 연필 아이콘으로 수정 가능(매니저 본인에게만 보임).

### 4.2 매니저 — 진도관리 탭
- **시험/평가 등록**: 시험명, 시험일, 메인 시험 여부. 여러 개 등록 가능(중간고사 외 수행평가·모의고사 등).
- **과목별 목표 등록**: 시험 안에서 과목별 목표 등급/점수/등수.
- **교재·범위 등록**: 과목 목표 안에서 교재명 + 범위를 등록.
  - **페이지 범위 모드**: 시작~끝 페이지 입력 → 월간 미니 캘린더에서 날짜를 여러 개 선택하면 총 페이지를 균등 분배해서 그 날짜들에 숙제로 즉시 생성(지연 생성 아님, 그 자리에서 바로 DB에 씀).
  - **자유입력 모드**: 페이지가 아닌 학습 내용(예: "1회 모의고사 풀이 및 채점")을 직접 입력.
  - 이미 등록한 범위는 수정 가능 — **지났거나 완료된 날짜는 절대 건드리지 않고, 남은 날짜만 다시 나눠 담는다** (과거 보존 원칙).
  - 시험/과목/범위 삭제 시, 아직 지나지 않고 완료되지 않은 미래 항목은 함께 삭제되고, 지났거나 완료된 항목은 연결만 끊고 기록으로 남긴다.
- **시험 일정은 학생에게도 읽기 전용으로 공유**된다(4.4 참고).

### 4.3 매니저 — 홈 탭
- 오늘 하루 학습 타임라인(체크리스트 + 시간대 그리드, 4.6 참고)을 상단에 고정 표시.
- 오늘 숙제 / 오늘 스스로 짠 계획 목록. 숙제 항목은 그 자리에서 "오늘 분량" 텍스트를 연필로 바로 수정 가능(수정 시 남은 분량이 자동으로 미래 날짜에 재분배됨) — 자기 계획 항목은 읽기 전용(학생 본인 것이므로 매니저가 대신 바꿀 이유가 없음).
- 숙제 항목은 삭제 가능(자기 계획 항목은 삭제 불가).

### 4.4 매니저 — 캘린더 탭
- 월간 그리드. 과외 요일은 배경색으로 표시, 공휴일/일요일은 빨간 글씨(2026년 공휴일 데이터 반영).
- 날짜 셀에 **그날 완료율을 나타내는 원형 링**(12시 방향부터 시계 방향, 완료 비율만큼 채워짐) — 과거 날짜에만 표시.
- 시험일에는 빨간 테두리 + 점 마커, 선택한 날짜가 시험일이면 헤더에 시험명 표시.
- 날짜를 선택하면 그날 숙제/계획 목록(진행률 링과 별개로 각 항목의 상세)이 아래 표시.
- **과외 요일 설정**: 요일 다중 선택으로 반복 패턴 등록(관리자당 1개).
- **특정 날짜 예외 처리**: 이번만 취소 / 다른 날로 변경 — 캘린더에 즉시 반영.

### 4.5 학생 — 홈 탭
- 오늘 할 일(숙제 + 스스로 짠 계획)이 **과목별 타이머 카드**로 나열됨. 각 카드는 과목명(문제집명)만 표시 — 상세 범위는 카드에 없음.
- **시작 / 일시정지 토글 버튼**: 시작하면 실시간 경과 시간이 표시되고, 일시정지해도 시간이 사라지지 않고 그대로 남아 다시 시작 시 이어서 누적된다(하루 동안 여러 번 쉬어도 총 학습 시간이 보존됨).
- 시간이 하나라도 쌓이면 **"오늘 학습 완료!!"** 버튼이 나타나고, 누르면 그 항목이 홈 목록에서 사라진다(완료 처리).
- **"오늘의 할 일" 버튼**(포스트잇 스타일, 당근 아이콘 + 화살표): 누르면 칠판 오버레이가 열리며 오늘 할 일 전체(과목, 문제집명, 범위, 완료 여부)를 확인 가능 — 홈 카드에서 뺀 상세 정보를 여기서 본다.
- **"어제 못한 숙제" 배너**: 홈 화면 맨 위, 어제 미완료 항목이 있으면 노출. 페이지 범위 숙제는 이미 자동 재분배됐다는 걸 알리고, 자유입력/자기계획 항목은 **"오늘 일정에 추가하기"** 버튼으로 오늘 날짜에 복사 가능(원본은 과거 기록으로 그대로 남음). "지금까지 밀린 과제 보기" 버튼으로 캘린더 탭 이동.

### 4.6 학생 — 스터디플래너 탭
- 상단에 **원형 진행률 링**("플래너 진행률") — 오늘 전체 할 일 중 완료 비율.
- 상단에 시험 일정 섹션(4.4에서 등록한 것을 읽기 전용으로) — 과목별 목표·교재 범위까지 펼쳐볼 수 있음.
- **스스로 계획 추가**: 과목·할 일·시작/종료 시간 입력해서 오늘 계획 추가/삭제.
- **오늘 타임라인**: 체크리스트(왼쪽, 과목 색 점 + 오늘 누적 공부 시간) + 시간대별 그리드(오른쪽, 10분 단위 칸으로 실제 공부한 시간대 시각화) — 매니저 홈 탭과 같은 컴포넌트 재사용.
- **완료한 학습** 섹션: 완료된 자기 계획 항목만 타임라인 아래로 분리(취소선 + 반투명).

### 4.7 학생 — 캘린더 탭
- 매니저 캘린더와 동일한 월간 그리드(과외 요일, 공휴일, 시험일 마커, 완료율 링) — 읽기 전용(일정 변경은 매니저 몫).
- 날짜 선택 시 그날 항목 목록.

### 4.8 밀린 숙제 자동 재분배 (핵심 로직)
- 페이지 범위로 등록된 숙제 한정. 놓친 날(과거 + 미완료)이 있으면, 완료된 항목들 중 가장 뒤 페이지를 "실제 도달 지점"으로 보고 남은 분량을 아직 완료 안 된 오늘/미래 날짜에 자동으로 다시 나눔.
- 놓친 날 항목 자체는 절대 수정하지 않음 — 캘린더 X 표시와 "어제 못한 숙제" 배너의 근거 기록으로 남김.
- 학생 본인 로그인 시 + 매니저가 그 학생 화면을 열 때, 양쪽 다 동일하게 계산·반영.
- 계산 결과가 이미 반영된 상태와 같으면 아무것도 쓰지 않음(멱등성) — 매번 앱을 열 때 돌아도 안전.

### 4.9 딴짓 멈춰 (안드로이드 전용)
- 학생 앱 우측 하단 원형 버튼(자물쇠 아이콘). 누르면 오버레이로 진입.
- 쉬는 시간 타이머, 차단할 앱 선택(인스타그램/유튜브/틱톡), 쉬는 시간 종료 시 동작(즉시 차단/확인 후 종료/유예시간), 허용앱(학습 실행 중 이탈 감지 예외) 설정.
- 실제 차단은 네이티브(Kotlin, Capacitor 플러그인)에서 동작 — 웹에서는 설정 UI만 제공.
- 학생이 실제로 학습 타이머를 켠 상태에서 허용 안 된 앱으로 이탈하면 네이티브가 감지해 세션을 자동 종료 처리.

## 5. 데이터 모델 요약 (Supabase / Postgres)

| 테이블 | 역할 |
|---|---|
| `sb_profiles` | 사용자 프로필(역할, 초대코드 등) |
| `sb_student_manager_links` | 학생-매니저 연결(+ 매니저별 라벨) |
| `sb_planner_items` | 날짜별 학습 항목(숙제/자기계획 공통) — 이 앱의 핵심 테이블 |
| `sb_study_sessions` | 항목별 시작~종료 학습 세션(일시정지 반복 시 여러 개 쌓임) |
| `sb_exam_records` / `sb_exam_subjects` / `sb_exam_subject_ranges` | 시험 → 과목별 목표 → 교재 범위 계층 |
| `sb_tutoring_schedules` / `sb_tutoring_schedule_exceptions` | 과외 요일 반복 패턴 + 날짜별 예외 |
| `sb_homework_assignments` | 레거시 지연 생성 숙제(현재 매니저 흐름에서는 사용 안 함, 구 버전 호환용) |

모든 테이블은 RLS로 보호되며, "연결된 매니저"(`sb_student_manager_links`) 관계를 통해서만 다른 사용자의 행에 접근 가능. 학생 본인은 자기 시험/과외 스케줄 데이터를 읽기 전용으로 조회할 수 있는 별도 정책이 추가되어 있다.

## 6. 기술 스택

## 7. 알려진 백로그 / 아직 안 한 것

브레인스토밍 및 리뷰 과정에서 나왔지만 이번 스냅샷 기준 미구현인 항목:

- **당근/토끼 마스코트 최종 아트웍** — 완료율 링은 현재 앱 primary 색상으로만 표시, 마스코트 스킨은 디자인 미정.
- **주간/기간 요약 리포트** — 매니저가 매일 안 들어와도 "이번 주 완료율 80%" 같은 걸 볼 수 있는 뷰.
- **알림(푸시/카카오 등)** — 숙제 시작 안 했을 때/완료했을 때 매니저에게 알림.
- **매니저 캘린더의 시간대 상세 그리드** — 현재는 완료율 링까지만, 학생 스터디플래너의 "오늘 타임라인" 같은 상세 시간대 뷰는 매니저 캘린더엔 없음.
- **여러 매니저 동시 연결 시 최근 수정자 표시** — 과외쌤+학부모가 같은 학생에 연결됐을 때 누가 마지막으로 뭘 바꿨는지 구분 불가.
- **세션이 안 끝나고 방치되는 근본 원인** — 브라우저를 그냥 닫으면 학습 세션이 DB에서 영영 안 끝난 채로 남는 문제, 화면 표시(타임라인 집계)는 우회했지만 근본 수정은 아직.
- **RLS 정책 누락 패턴 전수 점검** — 이번 개발 중 같은 유형의 버그(정책 없어서 조용히 실패)가 여러 차례 발견·수정됨, 나머지 테이블 전체를 훑는 작업은 안 함.
- **밀린 숙제 재분배가 자유입력/자기계획까지 확장** — 현재는 페이지 범위 숙제만 자동 재분배, 나머지는 수동 복사.
