# 스터디 벅스 — PRD (Product Requirements Document)

**최신화 기준일:** 2026-08-20
**브랜치:** `tutor-student-two-track`
**작성 배경:** 투트랙(과외쌤·학부모용 / 학생용) 전환 이후 지금까지 실제로 구현·배포된 기능을 기준으로 정리한 문서. 계획 단계 문서가 아니라 **현재 서비스 중인 앱의 스냅샷**입니다. (구 프로젝트명 "스터디 버디" → "스터디 벅스"로 개명)

## 1. 문제의식 & 방향성

과외를 진행하면서 학생들이 숙제를 매일 하지 않고 몰아서 하는 경우가 많고, 부모님/과외쌤은 이를 확인할 방법이 없다는 문제에서 출발했다.

- **과외쌤/학부모**는 아이의 학습을 확인·관리할 수 있어야 한다 — 숙제를 지정하고, 매일 얼마씩 하도록 정하고, 실제로 했는지 확인.
- **학생**은 최대한 단순한 화면으로, 과외쌤이 짜준 계획 + 스스로 짠 계획을 오늘 할 일로 받아서 시작/완료하면 되는 흐름.

이 문제의식에 따라 기존 단일 앱을 **매니저(과외쌤·학부모)용**과 **학생용**, 두 갈래로 나눴다(투트랙).

### 제품 철학 (2026-08-21 확정)

> **"사용하면 좋다"가 아니라 "사용하지 않으면 불편해서 스스로 쓰게 된다."**

순수 보상형 동기부여(뱃지, 완료율 %)보다 **손실회피(loss aversion)** 구조가 습관 형성에 더 효과적이라는 판단. 학생 대상 기능을 설계·검토할 때마다 이 질문을 먼저 던진다: *"이게 안 썼을 때 불편함을 만드는가, 아니면 그냥 썼을 때 기분 좋은 보상인가?"* 후자라면 우선순위를 낮추거나 손실 프레이밍으로 바꿀 방법을 찾는다.

- 이미 이 철학대로 동작 중: **"어제 못한 숙제" 배너**(안 하면 다음날 눈앞에 남음), **매니저가 매일 학생 현황을 보는 구조 자체**(안 하면 남이 안다는 사회적 압박).
- 편의 기능(반복 계획 자동 생성 등)을 넣을 때도 "자동화가 안 챙겨도 되는 느낌을 줘서 불편함을 없애버리지 않는지" 항상 재검토한다.
- 접근성(폰트 크기, 온보딩 등)은 이 철학과 별개로 디자인 트랙에서 별도로 다룬다.

**운영 중 받은 핵심 피드백과 방향 전환**: 학생 사용성을 넓히려면 "SNS 차단(딴짓 멈춰)"처럼 제약을 거는 기능보다, 타이머·모의고사 카운트다운·학습기록처럼 학생이 자발적으로 쓰고 싶어지는 자기주도 도구의 비중을 높이는 게 수용성이 높다는 판단하에, 모의고사 타이머 등을 추가하고 향후 암기장(플래시카드)은 별도 앱으로 분리하기로 했다(§9 백로그 참고). 또한 매니저 쪽 사용성 피드백("복잡하고 손이 안 간다")을 받아 화면을 늘리는 대신 **정보 위계 재정리**(학생 목록에 오늘 숙제 요약 배지 노출, 흩어진 기능 링크를 아이콘 액션 줄로 통합)로 대응했다.

## 2. 사용자 & 역할

| 역할 | 정의 | 진입 |
|---|---|---|
| 학생 | 자신의 계정으로 로그인, 초대코드로 과외쌤/학부모와 연결 | 회원가입 시 role 선택 |
| 매니저 (과외쌤 / 학부모) | 학생의 초대코드를 입력해 연결, 여러 학생 담당 가능 | 회원가입 시 role 선택 → 학생 목록에서 코드 입력해 연결 |
| 운영자(admin/operator) | 서비스 자체를 운영 — 배너, 회원 통계, 전체 공지 푸시 | 별도 관리자 웹(`/admin`)에서 이메일/비밀번호 로그인, 셀프 가입 불가 |

한 학생에게 과외쌤과 학부모가 동시에 연결될 수 있다(다대다). 각 매니저는 학생에게 자신만 보는 별칭(라벨)을 붙일 수 있고, 학생도 매니저에게 별칭을 붙일 수 있다.

## 3. 서비스 구조 (도메인 & 배포 단위)

하나의 Supabase 프로젝트(DB/Auth/Edge Functions)를 세 개의 독립 배포가 공유하는 구조.

| 배포 단위 | 도메인 | 성격 |
|---|---|---|
| 메인 앱 (`tutor-student-two-track`) | `app.studybuks.store` | 학생/매니저가 실제로 쓰는 React SPA. Capacitor로 감싸 안드로이드 APK로도 배포 |
| 관리자 웹 (`admin/`) | `app.studybuks.store/admin` (메인 앱 도메인의 rewrite로 프록시) | 별도 Vite 프로젝트, 별도 Vercel 배포 — 배너/회원/브로드캐스트 푸시 관리 |
| 소개 랜딩페이지 (`landing/`) | `studybuks.store` (루트 도메인) | 별도 Vite 프로젝트, 별도 Vercel 배포 — 서비스 소개 + 다운로드 안내. 앱 로직 없음 |

- 안드로이드: Google Play 미등록 상태로, 빌드한 APK를 Google Drive 링크로 직접 배포(비공식 사이드로드). 학생 수가 적어(파일럿 단계) Play 콘솔 등록 비용 대비 실익이 낮다고 판단.
- iOS: 네이티브 앱은 스캐폴딩만 되어 있고 빌드/배포된 적 없음(Mac 필요, 현재 개발 환경은 Windows). 대신 `app.studybuks.store`를 사파리로 열어 "홈 화면에 추가"하는 PWA 방식으로 안내. "딴짓 멈춰"는 애초에 안드로이드 전용이라 iOS에서 노출되지 않음.

## 4. 정보구조 (IA)

### 매니저 앱
- **학생 목록 화면**(진입점): 담당 학생 카드 목록, 각 카드에 "오늘 숙제 N/M 완료" 요약 배지(색상으로 완료/미완료 구분).
- 학생 선택 후 3탭: `캘린더` · `홈` · `진도관리` (상단에 선택된 학생 칩 고정, 연필 아이콘으로 별칭 수정)
- 캘린더 탭 상단에 **아이콘 액션 줄**(숙제 제안 / 시간표 / 요일 설정) — 예전엔 화면마다 흩어진 작은 밑줄 텍스트 링크였던 것을 한 자리로 통합.

### 학생 앱 — 3탭
`캘린더` · `홈` · `스터디플래너` (홈이 가운데)
+ 우측 하단 플로팅 버튼: **딴짓멈춰** (탭이 아닌 오버레이로 진입, 안드로이드 전용)
+ 홈 화면 상단 링크: **모의고사 타이머** (오버레이로 진입)

### 관리자 웹(`/admin`)
로그인 후 역할에 따라: `배너 관리`(운영자·관리자 공통), `회원 현황`·`브로드캐스트 알림`·`운영자 관리`(관리자 전용), `내 계정`.

## 5. 기능 명세

### 5.1 매니저 — 학생 목록 & 연동
- 담당 학생 목록에 초대코드 입력 폼 + 학생 카드 목록. 각 카드에 오늘 숙제 완료 현황 요약(전체 학생을 한 번에 미리 로드해서 계산).
- 학생을 선택하면 상단에 칩으로 고정, 다른 학생으로 즉시 전환 가능.
- 학생별 별칭을 연필 아이콘으로 수정 가능(매니저 본인에게만 보임).

### 5.2 매니저 — 진도관리 탭
- **시험/평가 등록**: 시험명, 시험일, 메인 시험 여부. 여러 개 등록 가능(중간고사 외 수행평가·모의고사 등).
- **과목별 목표 등록**: 시험 안에서 과목별 목표 등급/점수/등수.
- **교재·범위 등록**: 과목 목표 안에서 교재명 + 범위를 등록.
  - **페이지 범위 모드**: 시작~끝 페이지 입력 → 월간 미니 캘린더에서 날짜를 여러 개 선택하면 총 페이지를 균등 분배해서 그 날짜들에 숙제로 즉시 생성(지연 생성 아님, 그 자리에서 바로 DB에 씀). 등록·수정 성공 시 학생에게 푸시 알림.
  - **자유입력 모드**: 페이지가 아닌 학습 내용(예: "1회 모의고사 풀이 및 채점")을 직접 입력.
  - 이미 등록한 범위는 수정 가능 — **지났거나 완료된 날짜는 절대 건드리지 않고, 남은 날짜만 다시 나눠 담는다** (과거 보존 원칙).
  - 시험/과목/범위 삭제 시, 아직 지나지 않고 완료되지 않은 미래 항목은 함께 삭제되고, 지났거나 완료된 항목은 연결만 끊고 기록으로 남긴다.
- **시험 일정은 학생에게도 읽기 전용으로 공유**된다(5.6 참고).

### 5.3 매니저 — 홈 탭
- 오늘 하루 학습 타임라인(체크리스트 + 시간대 그리드, 5.8 참고)을 상단에 고정 표시.
- 오늘 숙제 / 오늘 스스로 짠 계획 목록. 숙제 항목은 그 자리에서 "오늘 분량" 텍스트를 연필로 바로 수정 가능(수정 시 남은 분량이 자동으로 미래 날짜에 재분배됨) — 자기 계획 항목은 읽기 전용.
- 숙제 항목은 삭제 가능(자기 계획 항목은 삭제 불가).
- **내가 제안한 숙제** 섹션: 이 학생에게 보낸 숙제 제안(5.9)의 대기중/수락됨/거절됨 상태를 한눈에 확인.

### 5.4 매니저 — 캘린더 탭
- 상단 **아이콘 액션 줄**: 숙제 제안 / 학교 시간표(읽기 전용) / 과외 요일 설정.
- 월간 그리드. 과외 요일은 배경색으로 표시, 공휴일/일요일은 빨간 글씨(공휴일 데이터 반영).
- 날짜 셀에 **그날 완료율을 나타내는 원형 링**(완료 비율만큼 채워짐) — 과거 날짜에만 표시.
- 시험일에는 빨간 테두리 + 점 마커, 선택한 날짜가 시험일이면 헤더에 시험명 표시.
- 날짜를 선택하면 그날 숙제/계획 목록, 그날 보낸 숙제 제안 상태가 아래 표시.
- **과외 요일 설정**: 요일 다중 선택으로 반복 패턴 등록(관리자당 1개).
- **특정 날짜 예외 처리**: 이번만 취소 / 다른 날로 변경 — 캘린더에 즉시 반영.

### 5.5 숙제 제안하기 (매니저 → 학생)
- 매니저가 캘린더에서 날짜를 고르고 아이콘 액션 줄의 "숙제 제안"으로 과목·교재·범위를 입력해 제안 전송.
- 학생 홈 화면에 제안 카드가 뜨고 체크(수락)/X(거절) 버튼으로 즉시 응답. 수락하면 그 날짜의 숙제로 바로 반영, 거절하면 사라짐.
- 제안 전송 시 학생에게 푸시 알림. 매니저는 홈 탭·캘린더 탭 양쪽에서 보낸 제안들의 상태(대기중/수락됨/거절됨)를 확인 가능.

### 5.6 학생 — 홈 탭
- 오늘 할 일(숙제 + 스스로 짠 계획)이 **과목별 타이머 카드**로 나열됨.
- **시작 / 일시정지 토글 버튼**: 시작하면 실시간 경과 시간이 표시되고, 일시정지해도 시간이 사라지지 않고 그대로 남아 다시 시작 시 이어서 누적된다. 일시정지 시점엔 화면에 보이던 값을 그대로 저장해서(재계산 없음) 순간적으로 숫자가 튀는 문제를 없앴다. 시작 시에도 서버 응답을 기다리지 않고 로컬에서 즉시 타이머가 돌기 시작한다(낙관적 업데이트).
- 시간이 하나라도 쌓이면 **"오늘 학습 완료!!"** 버튼이 나타나고, 누르면 그 항목이 홈 목록에서 사라진다(완료 처리) — 학생이 완료하면 매니저에게 푸시 알림.
- **"오늘의 할 일" 버튼**: 누르면 오늘 할 일 전체(과목, 문제집명, 범위, 완료 여부)를 확인 가능.
- **"어제 못한 숙제" 배너**: 어제 미완료 항목이 있으면 노출. 페이지 범위 숙제는 자동 재분배, 자유입력/자기계획 항목은 **"오늘 일정에 추가하기"** 버튼으로 오늘 날짜에 복사 가능.
- **숙제 제안 카드**(5.5): 매니저가 보낸 제안을 체크/X로 응답.
- **모의고사 타이머 링크**: 과목별 실제 시험시간(국어 80분/수학 100분/영어 70분/한국사 30분/탐구 30분/제2외국어 40분 프리셋 + 직접입력) 카운트다운. 일시정지/재개/종료 지원, 종료 시 실제 사용 시간 표시. 별도 홈 배너처럼 상단에 노출.
- **홈 배너**: 관리자가 등록한 공지/이벤트 배너(기간 내에만 노출, 세션 안에서만 닫기 가능).

### 5.7 학생 — 스터디플래너 탭
- 상단에 **원형 진행률 링**("플래너 진행률") — 오늘 전체 할 일 중 완료 비율.
- 상단에 시험 일정 섹션(5.2에서 등록한 것을 읽기 전용으로).
- **스스로 계획 추가**: 과목·할 일·시작/종료 시간 입력해서 오늘 계획 추가/삭제.
- **오늘 타임라인**: 체크리스트(왼쪽) + 시간대별 그리드(오른쪽) — 매니저 홈 탭과 같은 컴포넌트 재사용.
- **완료한 학습** 섹션: 완료된 자기 계획 항목만 타임라인 아래로 분리.

### 5.8 학생 — 캘린더 탭
- 매니저 캘린더와 동일한 월간 그리드(과외 요일, 공휴일, 시험일 마커, 완료율 링).
- 상단 "학교 시간표" 버튼: 요일×교시별 과목을 직접 입력/수정하는 시간표(5.10 참고).
- 날짜 선택 시 그날 항목 목록.

### 5.9 학교 시간표
- 학생이 캘린더 탭에서 직접 등록: 월~금 × 1~8교시 그리드, 칸을 눌러 과목 입력(빈 값으로 저장하면 삭제).
- 매니저는 자신이 담당하는 학생의 시간표를 같은 화면에서 읽기 전용으로 확인(과외 시간 잡을 때 참고).

### 5.10 밀린 숙제 자동 재분배 (핵심 로직)
- 페이지 범위로 등록된 숙제 한정. 놓친 날(과거 + 미완료)이 있으면, 완료된 항목들 중 가장 뒤 페이지를 "실제 도달 지점"으로 보고 남은 분량을 아직 완료 안 된 오늘/미래 날짜에 자동으로 다시 나눔.
- 놓친 날 항목 자체는 절대 수정하지 않음 — 캘린더 X 표시와 "어제 못한 숙제" 배너의 근거 기록으로 남김.
- 학생 본인 로그인 시 + 매니저가 그 학생 화면을 열 때, 양쪽 다 동일하게 계산·반영. 멱등성 있음(반복 실행 안전).

### 5.11 딴짓 멈춰 (안드로이드 전용)
- 학생 앱 우측 하단 원형 버튼(자물쇠 아이콘). 누르면 오버레이로 진입.
- **공부 중에는 허용앱이 아닌 앱에 들어갈 수 없다.** 학습 타이머가 도는 동안 학생이 미리 고른 허용앱과 생활 필수 앱만 열린다. 빠져나오는 길은 세 가지다 — 허용앱을 미리 설정하거나, 쉬는 시간을 쓰거나, `공부 끝내기`를 누른다.
- **생활 필수 앱은 고르지 않아도 항상 열린다**: 전화, 시계·알람, 설정, 홈 화면, 알림창, 키보드. 패키지명을 하드코딩하지 않고 시스템에 조회하므로 기기·제조사가 달라도 따라간다. 전화를 통과시키는 것은 안전 요구사항이다.
- **허용앱 고르기**: 홈 화면에 아이콘이 있는 앱을 아이콘·이름과 함께 목록으로 보여주고 토글로 고른다. 검색으로 걸러낼 수 있고, 이미 허용한 앱이 위로 모인다.
- **쉬는 시간**(+5/+10/+30분)을 시작하면 차단이 풀리고 학습 타이머가 멈춘다. 쉬는 동안에는 학습 시간이 쌓이지 않으므로, 길게 쓰면 그만큼 학습 기록이 비어 매니저 화면에 드러난다 — 사용 한도는 두지 않는다. **쉬는 시간이 끝나면 학생이 아무것도 누르지 않아도 차단이 복귀한다.**
- 공부 중 다른 앱을 열었을 때의 동작(즉시 차단/확인 후 종료/유예시간)을 설정할 수 있다.
- 화면 상단 배너가 지금 차단 중인지, 대기 중인지, 쉬는 시간인지, 허용앱을 아직 고르지 않았는지 알려준다.
- 상단 퀵컨트롤 알림에서 쉬는 시간을 시작하거나 `공부 끝내기`로 차단을 풀 수 있다 — 앱을 열 수 없는 상황의 탈출구. 딴짓멈춰 화면에도 같은 버튼이 있다.
- 학습 세션은 3시간이 지나면 자동 만료된다. 앱이 강제 종료돼 세션이 켜진 채 남아도 차단이 영구히 걸리지 않게 하는 안전장치.
- 설정 앱을 통과시키므로 학생이 접근성 권한을 직접 끌 수 있다. 마음먹으면 앱을 지우면 되므로 완전한 잠금은 애초에 불가능하며, 제품 철학은 "물리적으로 못 하게"가 아니라 "안 하면 티가 난다"다.
- 실제 차단은 네이티브(Kotlin, Capacitor 플러그인)에서 동작 — 웹에서는 설정 UI만 제공. iOS에서는 기능 자체가 노출되지 않음.

### 5.12 실시간 푸시 알림 (FCM)
안드로이드 기기 토큰을 등록해두면 다음 상황에 자동 발송 (Supabase Edge Function + FCM HTTP v1):

| 트리거 | 수신자 |
|---|---|
| 숙제 신규 등록/수정 (진도관리 범위, 레거시 배정) | 학생 |
| 숙제 제안 전송 | 학생 |
| 학생이 학습 완료 처리 | 매니저 |
| 학생이 자기 계획을 새로 세움 | 매니저 |
| 관리자 브로드캐스트 공지 | 전체 기기 |

발송 실패는 조용히 로그만 남기고("저장 실패"처럼 사용자에게 오류로 보이지 않게) 무효 토큰은 자동 정리한다.

### 5.13 관리자 웹 (`/admin`)
- 이메일/비밀번호 로그인, 셀프 가입 없음(최초 계정은 서비스 운영자가 Admin API로 부트스트랩).
- **관리자**(전체 권한) / **운영자**(배너 관리만) 두 등급.
- **배너 관리**: 제목/이미지/링크/노출 기간/활성 여부 등록·수정·삭제 → 학생 앱 홈 배너에 즉시 반영.
- **회원 현황**(관리자 전용): 전체 학생/매니저 수, 오늘/이번 주 가입자 수, 검색 가능한 회원 목록.
- **브로드캐스트 알림**(관리자 전용): 제목/내용 입력해 등록된 전체 기기에 즉시 푸시 발송.
- **운영자 관리**(관리자 전용): 운영자 계정 초대(임시 비밀번호 발급) / 삭제(로그인 계정 자체도 함께 삭제).
- **내 계정**: 비밀번호 변경 가능. 이메일 변경은 셀프서비스 플로우가 불안정해(SMTP 설정 이슈로 추정) 현재는 서비스 운영자가 Admin API로 대신 처리.

### 5.14 소개 랜딩페이지 (`studybuks.store`)
- 히어로: 마스코트 + 실제 앱 화면 스크린샷을 폰 목업 프레임에 넣어 노출(열품타 랜딩페이지 참고해 재설계).
- 핵심 기능 3개는 크게(지그재그 배치), 나머지는 컴팩트 리스트로 소개 — "N칸 균등 카드" 형태의 전형적인 AI 생성 레이아웃을 피함.
- 다운로드 & 이용 안내 섹션: 안드로이드 APK 다운로드 링크, iOS는 사파리로 웹앱 열어 홈 화면 추가하는 안내.
- 한글 텍스트가 단어 중간에서 줄바꿈되지 않도록 전역 `word-break: keep-all` 적용.

## 8. 알려진 백로그 / 아직 안 한 것

### 8.1 학생 동기부여 · 편의성 (제품 철학 기준 재우선순위화, 2026-08-21)
"손실회피" 철학([§1](#제품-철학-2026-08-21-확정))으로 순서를 매겼다 — 안 썼을 때 불편함을 만드는 것부터.

1. **숙제 미시작 시 매니저에게 알림** — 지금은 학생이 완료했을 때만 매니저에게 알림이 간다(§5.12). 정해진 시간까지 시작하지 않으면 매니저에게 알림이 가도록 반대 방향도 추가 — 안 하면 티가 난다는 걸 실시간으로 만드는 게 이 철학에 가장 직접적으로 부합.
2. **스트릭 (손실 프레이밍)** — "N일 연속 달성!" 배지가 아니라 "오늘 안 하면 N일 연속 기록이 끊겨요" 식 경고로 설계. 단순 보상형 배지보다 우선.
3. **반복 계획 템플릿** — 자기계획을 매번 새로 입력하지 않고 반복 등록. 단, 자동 생성이 "안 챙겨도 되는" 느낌을 줘서 철학과 충돌하지 않도록 — 자동 생성된 항목도 안 하면 "어제 못한 숙제" 배너에 그대로 남도록 설계해야 함.
4. **주간 요약 리포트** — 순수 보상형("이번 주 80% 완료")은 이 철학과 결이 약함. 넣는다면 손실 프레이밍("이번 주 3일 안 함")으로. 우선순위 낮음, §8.2 항목과 통합 검토.

### 8.2 그 외 백로그

- **암기장(플래시카드) 기능** — 별도 앱으로 분리하기로 결정(이 앱 범위 아님). 교재별 자동 단어 추출은 저작권·정확도 이슈로 보류, 향후엔 사진 OCR + 교재/범위 태그 기반 커뮤니티 단어장 공유 방식을 검토 중.
- **iOS 네이티브 앱** — 스캐폴딩만 존재, Mac 환경 확보 전까지는 사파리 PWA 방식으로 대체.
- **Google Play 정식 등록** — 현재 APK 사이드로드 배포, 사용자 늘어나면 재검토.
- **당근/토끼 마스코트 최종 아트웍 확장** — 캘린더 진행률 링 등 일부 UI에는 아직 마스코트 스킨 미적용.
- **매니저 캘린더의 시간대 상세 그리드** — 현재는 완료율 링까지만, 학생 스터디플래너의 "오늘 타임라인" 같은 상세 시간대 뷰는 매니저 캘린더엔 없음.
- **여러 매니저 동시 연결 시 최근 수정자 표시** — 과외쌤+학부모가 같은 학생에 연결됐을 때 누가 마지막으로 뭘 바꿨는지 구분 불가.
- **세션이 안 끝나고 방치되는 근본 원인** — 브라우저를 그냥 닫으면 학습 세션이 DB에서 영영 안 끝난 채로 남는 문제, 화면 표시(타임라인 집계)는 우회했지만 근본 수정은 아직.
- **관리자 내 계정 이메일 셀프 변경** — SMTP 설정 이슈로 추정, 현재는 서비스 운영자가 수동 처리.
- **모의고사 타이머 기록 저장** — 현재는 즉석 카운트다운 도구로만 동작, 과거 응시 이력은 저장하지 않음.
- **밀린 숙제 재분배가 자유입력/자기계획까지 확장** — 현재는 페이지 범위 숙제만 자동 재분배, 나머지는 수동 복사.
